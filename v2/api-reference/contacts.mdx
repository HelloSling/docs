Manage groups and contacts so you can target lists with one send call. Group and contact IDs returned here can be used as `group`, `groups[]`, `contact`, or `contacts[]` on any [send endpoint](/v2/api-reference/send).

## Headers

All Contacts API endpoints use the same headers.

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` *(POST)* |

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/groups` | List contact groups |
| `GET` | `/group-contacts/{groupid}` | List contacts in a group |
| `POST` | `/create-group` | Create a contact group |
| `POST` | `/add-contact` | Add one contact |
| `POST` | `/add-contacts` | Add multiple contacts |
| `POST` | `/update-contact/{contactid}` | Update one contact |

## GET /groups

```bash
GET https://app.sling.com.ng/api/v2/groups
```

Returns the contact groups in your account.

## GET /group-contacts/{groupid}

```bash
GET https://app.sling.com.ng/api/v2/group-contacts/{groupid}
```

<ParamField path="groupid" type="string" required>
  Group ID. Use `0` or `standalone` for ungrouped contacts.
</ParamField>

## Response convention

Contacts endpoints return `status: "success"` when the operation completes. Error responses return `status: "fail"` with a `details` message when available.
