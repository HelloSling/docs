## Endpoint

```bash
POST https://app.sling.com.ng/api/v2/send-email
```

The recipient on this endpoint is an email address rather than a phone number. Provide the address through `to`, or target saved contacts through `contact`, `contacts`, `group`, or `groups`.

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="sender" type="string" required>
  Approved email Sender ID (the `from` address registered for your account).
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line.
</ParamField>

<ParamField body="message" type="string" required>
  Plain-text email body.
</ParamField>

<ParamField body="html" type="string">
  HTML email body. When provided, recipients see the HTML version where supported.
</ParamField>

<ParamField body="type" type="string">
  Sender ID route. Accepted values: `transactional`, `promotional`, `otp`. Defaults to `transactional`.
</ParamField>

<ParamField body="callback" type="string">
  Public HTTPS URL that receives delivery updates.
</ParamField>

<ParamField body="reference" type="string">
  Custom message ID.
</ParamField>

<ParamField body="send_on" type="string">
  ISO datetime to schedule the message.
</ParamField>

<ParamField body="campaign_name" type="string">
  Label applied to multi-recipient campaigns.
</ParamField>

### Recipient (provide exactly one)

<ParamField body="to" type="string">
  Recipient email address.
</ParamField>

<ParamField body="contact" type="string">
  Saved contact ID. The contact must have an `email` set.
</ParamField>

<ParamField body="contacts" type="array">
  Array of saved contact IDs.
</ParamField>

<ParamField body="group" type="string">
  Single group ID.
</ParamField>

<ParamField body="groups" type="array">
  Array of group IDs.
</ParamField>

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the message is accepted.
</ResponseField>

<ResponseField name="message_id" type="string">
  Unique message ID. Use it with [Message Status](/v2/api-reference/message-status).
</ResponseField>

<ResponseField name="sender" type="string">
  Sender used for delivery.
</ResponseField>

<ResponseField name="recipient" type="string">
  Recipient email address.
</ResponseField>

<ResponseField name="credit_used" type="number">
  Credits deducted for this message.
</ResponseField>

## Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid request fields |
| `400` | Insufficient credit |
| `400` | Sender not approved for Email |
| `400` | Contact has no email address |
