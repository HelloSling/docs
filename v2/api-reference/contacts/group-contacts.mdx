## Endpoint

```bash
GET https://app.sling.com.ng/api/v2/group-contacts/{groupid}
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |

## Path parameters

<ParamField path="groupid" type="string" required>
  Group ID. Use `0` or `standalone` for ungrouped contacts.
</ParamField>

## Response

Returns contacts assigned to the group.
