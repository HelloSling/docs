## Endpoint

```bash
POST https://app.sling.com.ng/api/v2/add-contact
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="name" type="string" required>
  Contact name.
</ParamField>

<ParamField body="phone" type="string" required>
  Contact phone number.
</ParamField>

<ParamField body="email" type="string">
  Contact email address. Used by the Email channel.
</ParamField>

<ParamField body="group_id" type="string">
  Group ID or group `identifier` to assign the contact to. Leave empty or use `0` for standalone.
</ParamField>

<ParamField body="identifier" type="string">
  Optional identifier for the contact.
</ParamField>

<ParamField body="description" type="string">
  Description for the contact.
</ParamField>

## Response

### Success Response

Contacts endpoints return `status: "success"` when the operation completes.

```json
{
  "status": "success",
  "details": "Contact has been added successfully",
  "data": {
    "id": 156,
    "name": "HIIIII",
    "phone": "0903344",
    "email": "HII@gm.d",
    "identifier": null,
    "description": null,
    "created_at": "2026-05-28T11:50:25.000000Z"
  }
}
```
