Sling API v2 is the next version of the Sling messaging API. This workspace is reserved for v2 documentation while the current production API remains available in the v1 docs.

## Status

The v2 API is in development. Use the [v1 documentation](/v1/introduction) for current production endpoints until v2 is ready.

## Base URL

The planned v2 base URL is:

```bash
https://app.sling.com.ng/api/v2
```

Endpoint pages will be added here as the v2 API contracts are finalized.
