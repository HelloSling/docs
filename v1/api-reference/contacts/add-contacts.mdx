## Endpoint

```bash
POST https://app.sling.com.ng/api/v1/add-contacts
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="contacts" type="array" required>
  Contact objects to create.

  <Expandable title="contact object properties">
    <ParamField body="name" type="string" required>
      Contact name.
    </ParamField>
    <ParamField body="phone" type="string" required>
      Contact phone number.
    </ParamField>
    <ParamField body="email" type="string">
      Contact email address.
    </ParamField>
    <ParamField body="group_id" type="string">
      Group ID or group `identifier` to assign this contact. Leave empty or use `0` for standalone.
    </ParamField>
    <ParamField body="identifier" type="string">
      Optional identifier for the contact.
    </ParamField>
    <ParamField body="description" type="string">
      Description for the contact.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="group_id" type="string">
  Optional fallback group ID or group `identifier` to assign all contacts to.
</ParamField>

### Example payload

```json
{
  "contacts": [
    {
      "name": "John Doe",
      "email": "john@example.com",
      "phone": "1234567891",
      "group_id": "lagos-customers",
      "identifier": "john-doe",
      "description": "VIP customer"
    },
    {
      "name": "Jane Smith",
      "email": "jane@example.com",
      "phone": "0987654321",
      "group_id": 0,
      "identifier": "jane-smith",
      "description": "Standalone contact"
    }
  ]
}
```

## Response

### Success Response

Contacts endpoints return `status: "success"` when the operation completes.

```json
{
  "status": "success",
  "contacts_count": 2
}
```
