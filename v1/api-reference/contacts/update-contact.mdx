## Endpoint

```bash
POST https://app.sling.com.ng/api/v1/update-contact/{contactid}
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Path parameters

<ParamField path="contactid" type="string" required>
  Contact ID.
</ParamField>

## Body parameters

<ParamField body="name" type="string">
  Updated contact name.
</ParamField>

<ParamField body="phone" type="string">
  Updated contact phone number.
</ParamField>

<ParamField body="email" type="string">
  Updated contact email address.
</ParamField>

<ParamField body="group_id" type="string">
  Group ID or group `identifier` to assign the contact to. Leave empty or use `0` for standalone.
</ParamField>

<ParamField body="identifier" type="string">
  Optional identifier for the contact.
</ParamField>

<ParamField body="description" type="string">
  Description for the contact.
</ParamField>

## Response

### Success Response

Contacts endpoints return `status: "success"` when the operation completes.

```json
{
  "status": "success"
}
```
