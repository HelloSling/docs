## Endpoint

```bash
GET https://app.sling.com.ng/api/v1/status/{message_id}
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |

## Path parameters

<ParamField path="message_id" type="string" required>
  Message ID returned by a send endpoint.
</ParamField>

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the lookup completes.
</ResponseField>

<ResponseField name="status_delivery" type="string">
  Current delivery state, such as `"delivered"`, `"pending"`, or `"failed"`.
</ResponseField>

<ResponseField name="message_id" type="string">
  Message ID that was queried.
</ResponseField>

<ResponseField name="credit_used" type="string">
  Credits deducted when the message was sent.
</ResponseField>

<ResponseField name="sender" type="string">
  Sender ID used for delivery.
</ResponseField>

<ResponseField name="recipient" type="string">
  Normalized recipient phone number.
</ResponseField>

<ResponseField name="message_history" type="array">
  Prior delivery attempts for the message.
</ResponseField>

## Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing message ID |
| `400` | Invalid message ID |
