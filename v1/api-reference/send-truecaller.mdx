## Endpoint

```bash
POST https://app.sling.com.ng/api/v1/send-truecaller
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="to" type="string" required>
  Recipient phone number. Accepts local format, country code, or `+` prefix.
</ParamField>

<ParamField body="message" type="string" required>
  Message text. Maximum 3 pages.
</ParamField>

<ParamField body="sender" type="string" required>
  Registered Sender ID or brand name.
</ParamField>

<ParamField body="type" type="string">
  Sender ID route. Accepted values: `transactional` or `promotional`.
</ParamField>

<ParamField body="callback" type="string">
  Public HTTPS URL that receives delivery updates.
</ParamField>

<ParamField body="instant" type="boolean" default="false">
  When `true`, the request waits for immediate processing. When `false`, the message is queued.
</ParamField>

<ParamField body="contact" type="string">
  Saved contact ID. Use instead of `to`.
</ParamField>

<ParamField body="group" type="string">
  Contact group ID. Use instead of `to`.
</ParamField>

## URL parameters

This endpoint also supports URL-based sending with `api_token`, `to`, `message`, and `sender` as query parameters.

```bash
https://app.sling.com.ng/api/v1/send-truecaller?api_token=YOUR_API_TOKEN&to=08140363233&message=Hello&sender=Brand
```

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the message is accepted.
</ResponseField>

<ResponseField name="message_id" type="string">
  Unique message ID. Use it with [Message Status](/v1/api-reference/message-status).
</ResponseField>

<ResponseField name="sender" type="string">
  Sender ID or brand name used for delivery.
</ResponseField>

<ResponseField name="message" type="string">
  Message text.
</ResponseField>

<ResponseField name="recipient" type="string">
  Normalized recipient phone number.
</ResponseField>

<ResponseField name="credit_used" type="number">
  Credits deducted for this message.
</ResponseField>

## Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid request fields |
| `400` | Insufficient credit |
