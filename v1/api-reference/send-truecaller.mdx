## Endpoint

```bash
POST https://app.sling.com.ng/api/v1/send-truecaller
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="to" type="string" required>
  Recipient phone number. Accepts local format (without country code, where applicable), country code without `+`, or E.164 with `+` prefix — for example `08012345678`, `2348012345678`, `+2348012345678`, or `+14155552671`.
</ParamField>

<ParamField body="message" type="string" required>
  Message text. Maximum 3 pages.
</ParamField>

<ParamField body="sender" type="string" required>
  Registered Sender ID or brand name.
</ParamField>

<ParamField body="type" type="string">
  Sender ID route. Accepted values: `transactional` or `promotional`.
</ParamField>

<ParamField body="callback" type="string">
  Public HTTPS URL that receives delivery updates.
</ParamField>

<ParamField body="instant" type="boolean" default="false">
  When `true`, the request waits for immediate processing. When `false`, the message is queued.
</ParamField>

<ParamField body="ttl" type="integer">
  Time-to-live in seconds. If the recipient is not online or active on Truecaller within this window, the message expires and is not delivered. For example, `300` expires the message after 5 minutes.
</ParamField>

<ParamField body="fallback_sms" type="boolean" default="false">
  When `true`, Sling falls back to SMS if the message cannot be delivered over Truecaller.
</ParamField>

<ParamField body="fallback_sms_sender" type="string">
  Sender ID used for the SMS fallback when `fallback_sms` is `true`. For example, `Sling` while your Truecaller `sender` is `Brand`.
</ParamField>

<ParamField body="contact" type="string">
  Saved contact ID. Use instead of `to`.
</ParamField>

<ParamField body="group" type="string">
  Contact group ID. Use instead of `to`.
</ParamField>

## Message expiry

<Note>
  Set `ttl` to limit how long Sling keeps trying to deliver a Truecaller message. The value is in seconds — for example, `300` gives the recipient 5 minutes to come online. If they are not online or active on Truecaller before the window ends, the message expires and is not delivered.
</Note>

```json
{
  "sender": "Brand",
  "to": "08140363233",
  "message": "Your OTP is 482910",
  "type": "transactional",
  "ttl": 300
}
```

## SMS fallback

<Note>
  Set `fallback_sms` to `true` and Sling will re-send the message as a standard SMS if delivery over Truecaller is not possible. Use `fallback_sms_sender` to set the SMS Sender ID for that fallback (for example, `Sling` when your Truecaller `sender` is `Brand`).
</Note>

```json
{
  "sender": "Brand",
  "to": "08140363233",
  "message": "Hello from Truecaller",
  "type": "transactional",
  "fallback_sms": true,
  "fallback_sms_sender": "Sling"
}
```

## URL parameters

This endpoint also supports URL-based sending with `api_token`, `to`, `message`, and `sender` as query parameters.

```bash
https://app.sling.com.ng/api/v1/send-truecaller?api_token=YOUR_API_TOKEN&to=08140363233&message=Hello&sender=Brand
```

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the message is accepted.
</ResponseField>

<ResponseField name="message_id" type="string">
  Unique message ID. Use it with [Message Status](/v1/api-reference/message-status).
</ResponseField>

<ResponseField name="sender" type="string">
  Sender ID or brand name used for delivery.
</ResponseField>

<ResponseField name="message" type="string">
  Message text.
</ResponseField>

<ResponseField name="recipient" type="string">
  Normalized recipient phone number.
</ResponseField>

<ResponseField name="credit_used" type="number">
  Credits deducted for this message.
</ResponseField>

## Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid request fields |
| `400` | Insufficient credit |
