## Endpoint

```bash
POST https://app.sling.com.ng/api/v1/send-rcs
```

## Headers

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Authorization` | `Bearer {API_TOKEN}` |
| `Content-Type` | `application/json` |

## Body parameters

<ParamField body="sender" type="string" required>
  Registered Sender ID.
</ParamField>

<ParamField body="to" type="string" required>
  Recipient phone number. Accepts local format, country code, or `+` prefix.
</ParamField>

<ParamField body="type" type="string" required>
  Sender ID route. Accepted values: `transactional` or `promotional`.
</ParamField>

<ParamField body="template_type" type="string" required>
  RCS content type. Accepted values: `text`, `standalone`, or `carousel`.
</ParamField>

<ParamField body="message" type="string">
  Text message body. Required when `template_type` is `text`.
</ParamField>

<ParamField body="fallback_sms" type="boolean" default="false">
  When `true`, Sling falls back to SMS if the recipient does not support RCS.
</ParamField>

<ParamField body="suggestions" type="array">
  Interactive suggestion chip objects. See [RCS Suggestions](/v1/api-reference/rcs-suggestions).
</ParamField>

<ParamField body="standalone" type="object">
  Required when `template_type` is `standalone`.

  <Expandable title="standalone properties">
    <ParamField body="title" type="string" required>
      Card title.
    </ParamField>
    <ParamField body="description" type="string" required>
      Card description.
    </ParamField>
    <ParamField body="image" type="string" required>
      Public image URL.
    </ParamField>
    <ParamField body="orientation" type="string" required>
      Accepted values: `VERTICAL` or `HORIZONTAL`.
    </ParamField>
    <ParamField body="alignment" type="string">
      Accepted values: `LEFT` or `RIGHT`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="carousel" type="array">
  Required when `template_type` is `carousel`.

  <Expandable title="carousel item properties">
    <ParamField body="title" type="string" required>
      Card title.
    </ParamField>
    <ParamField body="description" type="string" required>
      Card description.
    </ParamField>
    <ParamField body="image" type="string" required>
      Public image URL.
    </ParamField>
  </Expandable>
</ParamField>

## Response fields

<ResponseField name="status" type="string">
  `"success"` when the message is accepted.
</ResponseField>

<ResponseField name="message_id" type="string">
  Unique message ID. Use it with [Message Status](/v1/api-reference/message-status).
</ResponseField>

<ResponseField name="sender" type="string">
  Sender ID used for delivery.
</ResponseField>

<ResponseField name="message" type="string">
  Text content for `text` messages.
</ResponseField>

<ResponseField name="recipient" type="string">
  Normalized recipient phone number.
</ResponseField>

<ResponseField name="credit_used" type="number">
  Credits deducted for this message.
</ResponseField>

## Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid request fields |
| `400` | Insufficient credit |
