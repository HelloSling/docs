Use `suggestions` in [POST /send-rcs](/v1/api-reference/send-rcs) to add interactive chips to an RCS message.

## Common fields

Every suggestion object includes these fields:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | Suggestion type |
| `text` | string | Yes | Label shown on the chip |
| `postback` | string | Yes | Value sent back when the user taps the chip |
